# WEIREN

Minimalist fashion storefront for WEIREN.

## Product assets

Add the supplied product photos under `images/` using these filenames:

- `black-front.png`
- `black-back.png`
- `grey-front.png`
- `grey-back.png`
- `maroon-front.png`
- `maroon-back.png`
- `navy-front.png`
- `navy-back.png`
- `brown-front.png`
- `brown-back.png`

The storefront currently uses the front images for product cards.
